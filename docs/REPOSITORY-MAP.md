# Repository map

The master repository contains the authoritative machine-readable list and dependency graph. This page is a human navigation aid.

- [agent-intelligence-ecosystem](https://github.com/PCakes303/agent-intelligence-ecosystem) — canonical public registry and governance.
- [agent-ai-discovery](https://github.com/PCakes303/agent-ai-discovery) — machine-readable discovery metadata.

- [agent-ecosystem-integration](https://github.com/PCakes303/agent-ecosystem-integration) — cross-repository contracts and synchronization.
